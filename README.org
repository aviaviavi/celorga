* Celorga

*Every AI agent you use. One workspace you own.*

Celorga is an open-source workspace for running AI agents on your notes, tasks,
meetings, and data. Everything is stored as ordinary =.org= files you own, and
the apps, editors, CLI, and agents all read them through one shared runtime.

[[https://celorga.io/][Website]] · [[https://celorga.io/downloads.html][Download]] · [[https://celorga.io/getting-started.html][Getting started]] · [[https://celorga.io/features.html][Features]] · [[https://celorga.io/reference.html][Developer docs]]

The website is the documentation. This README covers the basics and how to work
on the repository.

** What's here

- *The Celorga apps:* a native Mac app (agents, agenda, notes, meetings, data,
  publishing), an iPhone app, and a headless server for always-on agents.
- *The Celorga runtime:* an independently specified Org parser and semantic
  profile, the =celorga= CLI, an MCP server, a language server, and editor
  plugins for VS Code and Vim/Neovim. It has no Emacs dependency.

** Install

Download the Mac app from [[https://celorga.io/downloads.html][celorga.io/downloads]], or install the CLI on macOS
or Linux:

#+begin_src sh
npm i -g celorga
celorga agenda --dir ~/notes --recursive
celorga mcp serve --dir ~/notes
#+end_src

Agents can discover what the installed version supports with
=celorga agent capabilities=, and you can add Celorga's general agent skill to a
corpus with =celorga skill install --dir ~/notes= (preview first, then
=--apply=). See [[https://celorga.io/mcp-and-skills.html][MCP and agent skills]].

** Development

Requires Node.js 22. The Mac app also needs Xcode and Swift on macOS 14 or
later.

#+begin_src sh
npm ci
npm run build
npm run celorga -- --help      # run the CLI from this checkout
#+end_src

Tests:

#+begin_src sh
npm test                       # full Node suite (parallel; --jobs N to tune)
node test/test-NAME.mjs        # one focused test, after npm run build
npm run test:macos             # native macOS suite
npm run docs:check             # docs and capability manifest checks
#+end_src

Mac app: =npm run build:macos-app:codex= builds and installs an isolated
preview app with its own bundle identifier and a disposable demo corpus, and
=npm run open:macos-app:codex= launches it. =make macos-app= builds and replaces
your daily app instead.

Website: edit the Org sources under =docs/site/=, never the generated =site/=
directory, then regenerate it with:

#+begin_src sh
npm run celorga -- publish docs-site --config celorga.json
#+end_src

Pushes to =main= deploy the site to celorga.io.

** Contributing

Bug reports, Org edge cases that Celorga gets wrong, and pull requests are
welcome on [[https://github.com/aviaviavi/celorga/issues][GitHub]].

- Read [[file:AGENTS.md][AGENTS.md]] first. It is the repository guide for people
  and coding agents alike.
- Put language and automation behavior in the TypeScript runtime. Apps and
  editors consume it rather than parsing Org themselves.
- Add a focused regression test with each behavior change, and update the
  relevant page under =docs/site/= when user-facing behavior changes.
- Keep pull requests to one purpose.
