Review and safety

Agents do the routine work. Anything consequential waits for you.

  • One approval queueFrom files, agent runs, and mobile
  • Approve from iPhoneDeciding on one device updates the other
  • Drafts stay draftsAI-written content is marked until accepted
  • Previewed editsEvery agent change is a readable diff
  • Per-agent encryptionSeal a section to one person, device, or agent
  • Sourced answersAgent replies link to the file and line they used
  • Local by defaultNothing leaves your Mac unless you send it
  • Pinned pluginsLocked to exact commits and checksums

Writing and editing

A fast native editor for plain-text notes, rendered for reading and editable as source.

  • Reading, Source, SplitSwitch views without changing the file
  • Prose modeKeep alternatives, ghosted text, and cuts recoverable
  • Vim modeOptional Vim keybindings in the source editor
  • TablesSpreadsheet formulas in ordinary text tables
  • Live embedsShow another note or section inline
  • Link previewsHover a link to read the target
  • Web pages beside notesOpen links and local dev servers in place
  • Web ClipperSave articles and selections from the browser
  • Paste as OrgConvert rich text on paste (experimental)

Already use Org mode?

Open your existing ~/org folder. Celorga reads ordinary .org files, so there's nothing to import or convert. Headings, TODOs, schedules, properties, :ID: links, and org-roam notes work as they are, and the same files still open in Emacs.
